# HR-Analytics-Dashboard (Tableau)
"A Tableau dashboard analyzing employee attrition and satisfaction"
This projects analyzes HR data to understand attrition trends, satisfaction levels, and demographic distributions using Tableau.


## Dashboard Overview
**Total Employees:** - 1,470
**Attrition Rate:** - 16.12%
**Average Age:** - 37


## Key Features
Attritionby Department, Gender, Age Group
Education Field-wise Attrition
Job Satisfaction Rating Table
Interactive Filters(Education, Age bins)


## Tools Used
Tableau (for visualization)
Tableau prep Builder (for cleansing data)
Excel/CSV (for data source)
GitHub (for version control and sharing)
